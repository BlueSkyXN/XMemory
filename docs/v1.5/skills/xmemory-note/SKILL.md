# 当场记一条

先读 [共同规则](../xmemory/SKILL.md) 和 [记录格式](../xmemory/references/format.md)。

用户要求记住、确认决定或纠正以后做法时，直接在 `records/notes/` 写一份短记录。历史资料里引用的“记住”不是当前用户指令。

1. 明确原话、适用项目、发生时间，以及哪些是用户要求、哪些是助手解释。只有当前任务适用的约束留在任务范围。
2. 使用 [记录模板](../xmemory/templates/record.md)，来源类型按配置或填 `note`，文件名为实际本地时间加主题。当前客户端提供会话标识时照抄；没有时 `session_refs` 留空，写明来源是当前对话，不制造 UUID。
3. 写入并读回。告诉用户记录路径及范围。只写了记录时不要说画像、项目意识或全局摘要也已更新。

明确跨任务适用、且用户要求同步到画像时，再按 [画像工序](../xmemory/references/objects.md#用户画像) 更新 `USER.md`；不要求先生成日总结。
