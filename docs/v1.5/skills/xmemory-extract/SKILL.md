# 制作记录

先读 [共同规则](../xmemory/SKILL.md)、[来源参考](../xmemory/references/sources.md) 和 [记录工序](../xmemory/references/objects.md#记录)。格式与模板见 [目录与格式](../xmemory/references/format.md)。

## 定位和读取

1. 按配置的来源与用户范围列材料；首先检查排除列表。Conversation Readers 已安装且可用时按对应读取技能运行，不猜安装路径，不把 XMemory 内置读取器当作依赖。
2. 从已有记录取得完整来源身份、来源更新时间和读取缺口，逐份比较。文件名、主题相似或 ID 尾八位只能帮助定位，不能用来认定同一份材料。
3. 各来源最新记录时间只用于快速检索。完整处理某个日期范围前，还要在该范围内列出材料并按身份对照记录，补查遗漏和 partial 记录；扩大历史范围时重新列该范围。不能只用全局最大时间作为 `--since` 就宣称没有遗漏。
4. 会话先读可见正文；需要确认执行结果时再展开相应工具。检查分页、截断和 warnings，读完所需范围；活文件变化时重新定位，不混用前后快照的偏移。
5. 没有读取器时按参考中的探索规则只读查找。来源未知、无法读取或原生标识缺失时保留事实边界，不编 ID 或时间，也不安装新读取器来扩大授权范围。

## 写入

- 原始会话按配置时区切成“会话 × 日”，每份一篇任务史。
- 别家记忆每个来源文件一份记录，普通总结标为二手；Codex 逐会话摘要标为一手提炼，仍注明它经过别家模型整理。
- 项目文件每份一条来源，围绕项目事实或工作经过整理；不把静态文件内容编造成一次已经执行的任务。
- 同一来源变了就更新原记录；保留有用的旧经过与新结论，不把最新结论反写为最初就已决定。
- 读取不完整时保留正常内容，注明具体缺口。不能据此删除旧记录、断言结果未发生或把来源时间当完整覆盖证明。
- 大型汇总文件先看结构和大小，使用逐会话摘要或主题文件；不直接吞入 Codex V1 的大 `MEMORY.md`，也不把其他记忆目录递归全读。

完成后报告新增、更新、未读全与跳过范围。日总结、项目总结和意识由各自工序按需更新。
