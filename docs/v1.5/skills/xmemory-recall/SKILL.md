# 查阅记忆

根目录和边界见 [共同规则](../xmemory/SKILL.md)。只做查阅时不运行整库更新，不产生使用统计或新记忆。

1. 从 `memory_summary.md` 定位项目；缺少入口时直接查相应项目目录。需要偏好时读 `USER.md`。
2. 接续项目先读 `AWARENESS.md`；查稳定做法用 `MEMORY.md` 中的“什么时候看”定位主题。可用 `rg` 搜关键词、命令、报错或会话标识。
3. 按日期查工作时读全局 `daily/<年>/<日期>.md`，再读相关记录。不要求每一天都有文件。
4. 需要依据时沿主题、意识或画像的链接读 `records/`。需要核对原话、执行结果或二手转述时，再按 [来源参考](../xmemory/references/sources.md) 只读原会话或文件。

一般只读命中的少量文件，没有命中就停止扩大查阅。临时状态、版本、分支和部署等会变化的事实，核验便宜时现场核验；未核验时说明记忆的日期和可能过时。

回答注明来源链接、证据层级与未读边界。待确认、已替代和已撤回的条目不能直接当当前事实；来源冲突时说明冲突。没找到只表示本次范围内未找到。
