# 设置 XMemory

先读 [共同规则](../xmemory/SKILL.md) 和 [配置与格式](../xmemory/references/format.md)。建库、配置和告知都用文件工具完成。

## 建库与来源

1. 确认目标根、时区、用户选定的来源与项目。能从当前请求和环境确定的直接使用；未指定的来源不要自动开启。
2. 新空目录按 [配置模板](../xmemory/templates/config.toml) 创建配置与目录。对象在有内容时创建，不预造空的每日文件。
3. 已有 `xmemory/v1.5` 库时按现有配置补充；已有 1.4 或其他库时，保持原目录，说明新格式直接重建，先确定新的空目录或旧库归档位置，不静默覆盖。
4. 根据 [来源参考](../xmemory/references/sources.md) 核实用户选择的路径。有 Client Readers 时用 `memory locate` 选择存储位置；大批量建库优先用各客户端 `projects` 生成候选登记表，附会话数、记忆数与异常标记，按 parent 分组，交用户确认后写配置。无读取器时仍从实际工作目录和来源路径归纳候选。项目名与 roots 使用用户确认结果，worktree 或别名按确认归入；不从目录列表批量登记，子目录不重复登记。
5. 初次回填范围由用户目标或已选日期决定。未指定且历史量大时先说明拟处理范围；不把“最新一份记录”当作已回填全部历史。

## 告知与调度

- 按 [告知模板](../xmemory/templates/agents-notice.md) 填实际记忆根。只有用户要求集成到客户端时才合并到相应规则文件，保留原生记忆规则及其他内容，明确两套记忆共同使用；不自动注入记忆正文。读回确认没有把原生记忆入口改成只读 XMemory，也没有关闭原生记忆功能。
- 按 [定时提示词](../xmemory/templates/automation-prompt.md) 填日常增量范围；完整整理单独用 [周期整理提示词](../xmemory/templates/organization-prompt.md)，由客户端每 7 天触发。XMemory 不创建后台服务或保存上次整理时间；用户已要求创建客户端定时任务时，可用该客户端的能力完成。
- Client Readers 可另装；设置 XMemory 不代表授权安装或启用读取器。

回报实际创建或修改的配置、项目、选定来源与告知文件。配置完成不代表已读过外部来源或生成记忆。
