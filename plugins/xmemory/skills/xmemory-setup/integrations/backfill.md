## XMemory 首次回填提示词

首次把各客户端已有的记忆和历史会话导入集中库时使用。量大，按批手动执行；每批开一个新会话或交给一个 Agent，采集可以分头并行，整理只能一处进行。详细规则见采集技能的“首次回填”。

## 第 0 步：设置

```text
使用 xmemory-setup：
1. 初始化或检查 ~/.agents/memory/，确认 timezone 和 quiet_minutes。
2. 发现项目：列出各客户端的项目目录（ZCode、Claude、Qoder、Trae 的项目分区，Codex 记忆里的 cwd，各端会话的 cwd），按项目根目录汇总候选，项目名等于根目录名，登记各客户端别名；同名冲突写成 <名>@<父目录名>。先给我候选表确认，再写配置。
3. 登记来源：本机存在的各客户端原生记忆和会话目录，默认 enabled = false，由我确认后启用。
```

## 第 1 步：原生记忆（每个客户端一批）

```text
使用 xmemory-collect，首次回填·原生记忆：
来源：<一个来源 ID，例如 codex-memory>
时间段：全部历史
要求：
- 先写清单 state/runs/<日期>-回填-<来源>.md，从目录列表逐项抄录（每个摘要文件或聚合文件中的每个条目块一行），核对行数与列表一致。
- 每项写一份足迹到它的事件日期目录，范围按 route 判定；或标为无可记内容、跳过、失败。
- 完成后报告清单核对结果：总行数、各状态行数、空状态行数。
```

## 第 2 步：会话补缺口（按“项目 × 月份”分批）

```text
使用 xmemory-collect，首次回填·会话：
来源：<会话来源 ID>
项目：<项目名>
时间段：<YYYY-MM-01T00:00:00+08:00> ~ <下月 1 日同一时刻>
要求：
- 用读取工具按项目和时间段列出全部会话，分页取尽；先写清单，逐项抄录。
- 已被原生记忆足迹覆盖的会话标为“跳过：已由 <足迹链接> 覆盖”；其余逐个读取，一个会话一份足迹（跨天按天拆）。
- 只读已静默的会话；时间参数带时区；会话 ID 从读取结果复制，不截断。
- 完成后报告清单核对结果。
```

## 第 3 步：整理（每完成几批做一次）

```text
使用 xmemory-curate，手动方式，范围：<项目名或 personal>，处理全部未整理足迹；范围太大时按日期分批，剩余写进整理记录。
```

## 第 4 步：验收

```text
使用 xmemory-recall，只读，逐项回答并给出日期和来源：
- <项目名> 上次进行到哪一步？还有哪些待处理？
- <项目名> 的 <某个决定> 是怎么定的，为什么？
- <项目名> 里 <某类问题> 以前踩过什么坑，怎么避？
```

答不出、日期错误或来源打不开的，记下来，回到对应批次补采或修正。
