# 可选只读检查

基本采集、整理与查阅可直接使用宿主文件工具。仅需要机械盘点时运行 Python 3.9+ 标准库脚本：

```bash
python3 -B /absolute/path/to/skills/xmemory/scripts/xmemory.py status
```

正式根固定为用户 home 下的 `.agents/memory/`。`--root` 仅用于明确的开发夹具或诊断，`--summary` 省略逐文件清单。脚本不读取环境变量 XMEMORY_ROOT。

输出为 Markdown 文本，显示入口与主记忆是否存在、Markdown 数量与大小、缺失的内部文件目标和跳过的符号链接。只检查库内链接的文件目标是否存在，不校验标题锚点或追踪外部来源链接；不读取 config.toml，不解析旧格式元数据，不判断是否已经读全来源或记忆是否正确。

检查行内链接和使用单行定义的引用式链接，支持括号、转义和空格目标，跳过围栏及行内代码。带协议的外部地址直接跳过，不解析其地址格式。

报告生成成功退出 0，缺库或无法读取退出 2；报告中的问题仍需按实际用途判断。脚本始终只读，不创建目录、缓存、状态或记忆文件。
