# 查阅记忆

根目录和边界见 [共同规则](../xmemory/SKILL.md)。只做查阅时不运行整库更新，不产生使用统计或新记忆。

1. 从 `memory_summary.md` 定位项目；缺少入口时直接查相应项目目录。需要偏好时读 `USER.md`。
2. 接续项目先读 `AWARENESS.md`；查稳定做法用 `MEMORY.md` 中的“什么时候看”定位主题。可用 `rg` 搜关键词、命令、报错或会话标识。
3. 按日期查工作时先读全局 `daily/<年>/<日期>.md`；需要具体经过或关键依据时再展开相关记录。不要求每一天都有文件。
4. 回答偏好、决定或项目现状前，核对该范围记录里的相关更正、撤回和替代。除了入口已有的来源链接，还要直接检索 `records/notes/` 及相关会话、导入和文件记录，按项目、主题、关键原词及同义表述定位；入口尚未链接的记录也可能改变答案。日期只帮助优先定位，不能只读比全局摘要或目标文件 `updated` 更新的记录，局部更新可能晚于尚未处理的更正。
5. 对检索命中读取足够上下文；相关新记录可直接用于回答，无须等待上层对象更新。明确更正按适用范围采用，保留其他有效条件；较新的二手转述不自动推翻原件，单次要求不升级为长期偏好。存在影响答案的冲突、缺少关键依据，或需要核对原话、执行结果和二手转述时，再按 [来源参考](../xmemory/references/sources.md) 展开相关记录或原件；无法裁定则说明未知。

问题已有充分依据、相关更正已核对、剩余未知已明确时，结束查阅；不能沿旧链接找到一条支持就结束，也不为查阅做全库更新。需要定位待处理记录时可运行只读 `status`，`current` 不替代更正检查。临时状态、版本、分支和部署等会变化的事实，核验便宜时现场核验；未核验时说明记忆的日期和可能过时。

先直接回答，并给出关键来源。普通接续聚焦影响下一步的当前判断和行动，历史版本、测试明细等按需回查；用户要求复盘或核查时再展开经过、证据链与查阅范围。二手依据、过期、冲突或读取缺口影响结论时，说明具体影响。入口仍保留旧结论时说明尚未同步，查阅不改写它。待确认、已替代和已撤回条目不能当当前事实；没找到只表示本次范围内未找到。
