# 查阅记忆

共享记忆位于用户实际 home 下的 `~/.agents/memory/`。明确的开发试验使用指定测试根。当前请求优先于历史记忆。

1. 判断任务是否需要历史；需要时先读 `memory_summary.md`，结合项目路径或明确主题定位。
2. 先处理入口中与当前任务有关的更正、遗忘和待核查提示，确定哪些内容可采用。范围清楚的明确更正可直接使用；遗忘按指定范围排除；待核查保持未知，不将受影响的旧结论说成当前事实。提示不足时才展开相关现有内容，不以笔记已创建为前提。
3. 入口已给出足够答案就直接使用；否则只展开 `MEMORY.md` 的相关章节。对照用户所问的各项：入口或主记忆已经包含答案、范围及必要日期，就停止读取并回答，不为了补引用、重复确认或列出来源再打开笔记。主记忆中的条件与结论一起使用。
4. 用户追问经过、精确原话或依据，或已有内容出现实质冲突、答案缺口时，才沿链接展开相应 notes，再按需要回到原件。只读能够解决该具体问题的笔记，不跟随全部来源链接。入口缺失或链接失效时，仅按当前主题做定向查找并说明缺口。
5. 稳定要求和适用的方法可以直接采用；部署、版本和外部状态按当前任务需要检查现状。用户问“为什么”时保留变化依据，不能从一次尝试推导全局规则。

查阅保持记忆目录只读；发现矛盾时说明影响，不顺手整理或改文件。用户要求写入后，按意图转 [更新](../xmemory-update/SKILL.md) 或 [记住与更正](../xmemory-note/SKILL.md)。

需要理解文件职责或遗忘约束时再读 [共同约定](../xmemory/references/format.md)。入口中的“整理约束”适用于本次相关的原件回查；不要重新带入明确排除的内容。
