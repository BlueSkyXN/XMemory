# 运行一轮

先读 [共同规则](../xmemory/SKILL.md)，使用现有 `xmemory/v1.5` 配置。用户已要求执行且范围明确时，完成清点后直接做首批；有已授权的后续批次且能力允许时继续完成。

## 1. 定范围

模式按用户目标选择：日常更新为增量；补全或回填为补全；只整理现有记录为库内整理。根、时区、启用来源、项目映射、排除列表取自配置，日期、项目、对象和工作量取自请求。用一句话说明本轮范围。

没有配置时进入 [设置](../xmemory-setup/SKILL.md)。新增来源、扩大路径、旧库迁移或无法确定的项目合并需用户决定；已有授权沿用。具体项目优先级是本轮参数。

## 2. 清点

运行一次 `status --summary`，按 [报告约定](../xmemory/references/status.md) 读取 `inventory`、对象线索与问题。库内结果不检查外部材料。

采集范围内的外部材料用读取器或文件工具列出完整身份、来源版本和可知日期；读取已有记录的 `source_ref`、`source_updated`、`coverage`、`day` / `event_days`，用脚本对照，按以下四类归组：

| 类别 | 判断与下一步 |
|---|---|
| 未收录 | 没有对应范围的记录；会话按“会话 × 日”，导入或项目文件按实际来源文件，补上缺少的范围 |
| 需续读或更新 | 已有记录 partial、来源版本变化，或来源时间未知无法比较；回查原件并续读或更新 |
| 已对应 | 身份、版本与所需覆盖均一致，保留原记录 |
| 不可读 | 保留具体身份和失败原因，计入未完成 |

增量可按各来源最近的 `latest_source_updated` 筛选新材料，同时处理已有 partial、未知来源时间及库内缺口；不把这个时间当历史完整水位。补全在整个已选范围逐项核对，不设隐含时间窗。分页、上限和 warnings 处理完或明确列为清点缺口；未列全时剩余数量写未知。

启用的 Skysight 单独对照日总结“来源与覆盖”及活动块，按实际原件身份与窗口找遗漏；旧日文件仍从块内定位读取。它不生成记录，记录数为零不能说明活动覆盖。库内整理可跳过外部扫描。

清单保留在本轮上下文，不另存进度或运行状态文件。

## 3. 分批

超过一轮能力时，优先处理即将清除的原件，再处理用户指定的项目，其余由近到远。用“一个来源中的一个项目”或“一天”作为批次；以能完整处理对象的范围确定批量。

首批立即执行。无额外限制时继续完成已选范围；达到用户工作量或客户端时长、上下文限制时，停在批次边界，报告具体剩余项。下一轮重新从文件身份、版本与覆盖判断。

## 4. 写记录

按 [制作记录](../xmemory-extract/SKILL.md) 处理本批材料。会话一天一条，来源文件通常一份一条；同源事实在下游合并，保留各份出处。partial 可以先保存已读部分和真实时间，说明具体缺口。

Skysight 直接按 [活动摘要工序](../xmemory/references/sources-codex.md#skysight-活动摘要) 写日总结。extract 在本轮调度内完成后返回这里，其结果并入最终汇报。

## 5. 更新对象

按 [对象整理](../xmemory-consolidate/SKILL.md) 处理本批记录、`newer_sources`、`unlinked_sources` 和点名对象。索引为 current 时仍检查该项目所有主题的 stale / review / unknown；有内容才创建对象。主题先于索引，全局摘要取本轮最终入口和画像。

日文件与单个主题保存前检查该文件的待更新来源：全部在本次范围内、已处理完且无阻断扫描或元数据缺口时才保存。否则保留原文件，继续完成其他对象，并报告“日文件待整篇整理”或具体待整理主题。项目索引可以随已完成主题更新，其时间不表示整个项目已整理完。

补全时，画像和意识按选定范围枚举相关记录，不能只依赖时间提示。完整整理按对象工序执行。consolidate 在本轮内使用共享检查结果；有新记录或来源变化时，在保存前刷新必要的检查。

## 6. 收束

读回修改文件，再运行一次 `status --summary`。后写来源使先写对象过期时继续处理，或作为明确的未完成项。运行中出现的新材料能稳定纳入就处理，否则留待下一轮核对。

汇报固定四项，数字取实际清单与文件：

- **范围**：模式、来源、项目、日期、对象；外部是否检查及清点是否完整。
- **完成**：新增和更新记录数、实际更新的对象路径、已对应的材料数。
- **剩余**：各来源未处理数量或未知、partial / 不可读原因、待整理对象；只选部分对象与已选对象未完成分别说明。
- **继续**：下一轮可直接执行的一句话，例如“继续补全所选 Codex 会话摘要”。
