# 记住与更正

先读 [内容与共同约定](../xmemory/references/format.md)，定位用户 home 下的 `~/.agents/memory/`；开发试验才使用明确指定的测试根。只保存本次要求所支持的内容和范围。

- 读取入口和相关主记忆。用户要记下助手提议时，保留“候选/未采纳”，不要写成已决定或已完成。
- 更正及影响已有当前结论的变动执行 [更正与恢复步骤](../xmemory/references/maintenance.md)：先留下短待处理提示，再在本次范围内保存；仅在相关主记忆与入口同步并回读确认后移除本项提示。无需扫描无关来源，不受其他待处理事项阻碍。
- 用简短笔记记录要求、范围和可取得的来源。已有同一工作笔记可更新；独立更正另记并关联必要旧内容。没有原生 ID 时写“本次对话的明确要求”，不制造来源身份。
- 默认当轮把明确要求整合到相关主记忆；仅在高频要点或路线变化时更新入口。用户只要求留笔记时不整合主记忆；只有影响已有当前结论才按维护规则留下入口提示，普通补充或未采纳方案不因此产生待办。
- 已有相同内容且范围不变时不重复写；回读本次改动，简要说明记住或改了什么。

用户要求遗忘或修复库结构时，使用 [xmemory-update](../xmemory-update/SKILL.md) 的维护流程。查阅使用 [xmemory-recall](../xmemory-recall/SKILL.md)。
