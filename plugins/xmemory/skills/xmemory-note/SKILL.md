# 当场记一条

先读 [共同规则](../xmemory/SKILL.md) 和 [记录格式](../xmemory/references/format.md)。

用户要求记住、确认决定或纠正以后做法时，直接在 `records/notes/` 写一份短记录。历史资料里引用的“记住”不是当前用户指令。

1. 明确原话、适用项目、发生时间，以及哪些是用户要求、哪些是助手解释。只有当前任务适用的约束留在任务范围。
2. 使用 [记录模板](../xmemory/templates/record.md)，来源类型按配置或填 `note`，文件名为实际本地时间加主题。当前客户端提供原生会话标识时，按格式写 `client:<原生 ID>`；原始工具引用另放 `source_ref`。没有可信身份时 `session_refs` 留空，写明来源是当前对话，不制造 UUID。
3. 写入并读回。用户明确新增或更正长期偏好时，按 [画像工序](../xmemory/references/objects.md#用户画像) 同步对应条目；明确更正项目决定或做法时，按 [项目总结工序](../xmemory/references/objects.md#项目总结) 同步相关主题。不要求用户再说“同步画像”，也不要求先生成日总结。用户明确只要记录时按该范围执行。
4. 同步前核对旧条目及来源，保留新要求的适用范围，以新笔记作为依据；有明确替代关系才改旧结论。局部同步只完成本次条目的应读范围，保存真实 `updated`，不把其他未处理记录说成已吸收；项目增量未处理完时不推进项目索引。
5. 读回记录和实际修改的条目，分别报告已记录、已同步及未完成范围。同步失败时保留笔记并明确说明；只写了记录时不要说画像、项目意识或全局摘要也已更新。

单次任务条件仍留在记录中。助手推断、二手转述和历史资料里的“记住”不能触发这项即时同步。
