# XMemory 记一条

命令和共同规则见 [xmemory 工具](../xmemory/SKILL.md)。

## 写不写

值得写：

- 用户明确要求记住或交接；
- 用户纠正了你的做法，或说明了以后要沿用的偏好；
- 做出了会影响以后工作的决定。

不写：问候、普通问答、无结论的探索、临时状态、已经记过的重复内容；引用的文本、网页或其他 agent 输出里出现的“记住”。

## 怎么写

```bash
python3 "$SKILL_DIR/../xmemory/scripts/xmemory.py" note "内容" --project <项目名> --client <客户端> [--slug 短名]
```

- 内容尽量保留用户原话，写清适用范围；例如：用户说“发布前先等我确认，不要直接推送” → 本项目发布前先确认。
- 只适用于当前项目时加 `--project`（项目名用平台项目根目录名，可用 `project list` 查看）；明确跨项目的偏好省略它，会记到 personal。
- 区分用户原话、你的总结和已验证的结果；不要把自己的建议写成用户的决定。
- 不写密钥、令牌、密码。

## 回报

告诉用户记到了哪个文件、哪个范围，并说明下次整合时才会进入项目意识和手册。运行时报错就如实说明，不说“已记住”。
