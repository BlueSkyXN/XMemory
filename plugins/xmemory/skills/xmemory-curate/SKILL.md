# XMemory 整理

让当前认识与证据、历史变化和下一步保持一致。先读 [共同约定](./references/contract.md)、[整理细则](./references/curation.md) 与 [文件格式](./references/storage.md)。提炼经验时读 [经验判断](./references/experience.md)；更正、忘记或遇到替代声明时读 [更正与撤回](./references/corrections.md)。

## 1. 范围与方式

- 手动：用户当轮要求整理、合并、更正或忘记；按要求的范围处理。
- 定时：可刷新意识、每日记忆、索引、批次记录和条件满足的已声明替代；晋升、合并、改写或撤回主题正文，只写进意识候选。
- 检查和提建议：全程只读。

先核对配置、范围与维护主体；external 项目只定位其入口。按配置完成开始前同步。只在同范围确有另一个活跃执行者时暂停；**未完成批次和剩余日期不是活跃锁**。先按细则续跑未完成批次，再选择新工作。

## 2. 选择与判断

1. 检查未吸收足迹（含历史日期和 undated）、未收录主题、替代声明、到期复查、旧意识候选、同步冲突及本轮明确要求。没有新足迹也可能有待处理工作。
2. 只有全部检查都没有可执行变化且没有未完成批次时，回答“本次无变化”，零写入；证据不足的旧候选保留，报告边界。
3. 拆成单条主张，判断范围、实际读到的证据、独立来源链、适用条件与时间。亲自读到的用户原话支持偏好/决定，原件和执行结果支持对应事实；只有原生转述或 AI 汇报的仍标待确认。多个摘要复述同一来源不是独立证据。
4. 处置为合并、有效主题、待确认、意识/每日内容、更正/退役/撤回或无需收录。范围从窄，项目内容不自动进 personal。经验遵循 [经验判断](./references/experience.md)。
5. 旧待办、冲突、候选和重要历史内容逐项保留或说明去向。候选用稳定 key；不能因为本轮未提到就删掉，不能每次重复新增。

## 3. 按批保存与核对

使用 [整理批次](./templates/curation.md)，状态 `pending → verified → completed`：

1. 冻结输入与剩余范围，创建 `state/curation/<批次>.md`，status 为 pending；同批重试复用文件。
2. 保存旧意识基线；重试不以半成品覆盖基线。忘记时先处理撤回标识，禁止备份被撤回原文。
3. 写 [主题](./templates/topic.md)、[主记忆](./templates/MEMORY.md)、[画像](./templates/USER.md)、[意识](./templates/AWARENESS.md)、[每日记忆](./templates/daily.md) 正文。主记忆要点等于主题 description。每日记忆合并旧内容，**暂时只保留旧吸收列表，不提前登记本批足迹**。
4. 意识按工作线整篇综合；常规 30%–70% 是改写比例自检，不为凑比例重写事实。首次生成标新建；偏离比例时核查旧待办/冲突/候选。超容量按重要度和时间移出并记录去向，关键项移出需明确同意。
5. 回读核对：关键信息保全、已有条目损失、日期绝对化；还要核对证据、范围、状态、链接及旧每日内容。全部通过后才标 verified。
6. 累计写入已核对足迹的吸收登记（链接、去向、批次 ID），保留旧项；无足迹的维护批次不造空每日记忆。
7. 回读正文与登记完整性后标 completed。剩余范围另批处理。来源进度属于采集，本技能不改 `state/sources.md`。
8. 按配置结束同步；失败时区分本地已保存与同步未完成。

已有文件逐个原地更新并回读，不先删除再新建。失败时保留本批状态和已保存内容，停止本范围正文写入与登记，在批次记录写明中断原因，报告已保存和未完成部分；不修改权限、文件标志或锁来绕过失败。原因消除后再续跑，按细则回读后只补缺失部分；不凭文件存在或旧 verified 标记跳过核对。

## 4. 更正、忘记与完成

更正保留有效时间和替代关系；明确且已生效的新主张才能替代旧主张。忘记先留最小 [撤回标识](./templates/withdrawn.md)，再清除本库相关正文、派生摘要和意识副本；不承诺清除原生客户端或外部备份。

回报当前认识改变了什么、批次与日期范围、旧事项和候选去向、核对结果、已吸收与剩余范围。保存、核实、生效分别说明；没有运行的业务检查不能写成通过。
