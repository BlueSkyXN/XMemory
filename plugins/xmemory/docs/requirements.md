# 原始需求的覆盖情况

本文按 1.2.0 设计逐条对照用户最初提出的记忆设计，设计全文见 [设计](design.md)。用户原话里的结构就是本插件的骨架：采集（被动、主动）→ 整理（意识、主记忆、足迹、每日与项目记忆）→ 调取。

## 先区分技能、触发和存储

XMemory 负责“做什么、读哪里、留下什么、怎样找到”，由模型使用宿主现有的文件工具执行；插件不带独立程序。

“何时运行”由三样东西决定：
- 读取协议提示 Agent 在合适的时候读取或记录；
- 宿主的 Hook 在会话开始、压缩前、会话结束时提醒；
- 用户挂到某个客户端的定时任务执行后台采集与整理。

插件本身不计数、不监听、不在后台运行。文件存在不代表客户端会自动读取。

## 逐项对应

| 原始想法 | 当前对应 | 边界 |
|---|---|---|
| 被动采集：AI 在对话中主动写入 | 记录技能；`capture = "milestone"`（模板默认）时，被纠正、说明偏好、做出决定、阶段交接都会写足迹 | 依赖宿主按读取协议调用，不保证每次触发 |
| 被动采集：Hook 强制记忆，一步一 hook、五步一 hook，或让它自主判断 | Hook 接入模板：推荐会话开始、压缩前、会话结束三个事件，也给出按步数的写法；触发后由记录技能判断写不写 | 插件不安装 Hook；按步数触发成本高 |
| 主动采集：定时任务或 Agent 定时收集客户端的记忆来源 | 采集技能方式一：从各客户端原生记忆制作；定时提示词把采集和整理挂到任一客户端 | 插件不带调度器 |
| 主动采集：从多端对话记录、日志采集 | 采集技能方式二：从具体会话制作，可点名会话或按“项目 + 时间段” | 依赖宿主或已安装技能的只读读取方式，不解析未知数据库 |
| 主动采集：从工作区文件夹变动收集 | 采集技能方式三：Git 和修改时间缩小范围，再读必要内容 | 只作线索，不证明业务完成 |
| 不是复制，而是总结与索引，告诉 AI 去哪里找 | 足迹只存总结和规范地址；会话 ID、文件路径从读取结果复制，可回查 | 不保存整段聊天或完整日志 |
| 整理由一个 AI 代表我按规范进行，格式参考成熟经验 | 整理技能 + 整理细则：候选归一、证据等级、处置、晋升门槛、写后核对；格式参照 Claude/ZCode 的主题文件、QoderWork 的 awareness、Codex 的逐会话摘要 | 不承诺语义无损 |
| 意识：类似 Qoder 的意识，维护行动项、关键信息、决策；长期更新，刷新 30%–70%，类似重写，近期优先 | `AWARENESS.md` 五节；每次整篇重写，常规改写 30%–70%，近期优先；重写前存副本，重写后比对比例并核对待处理 | 比例是自检信号，不是凑数指标；旧待办不能无依据消失 |
| 主记忆：一个文件，包括子文件的信息抽取和整理，来引导关键信息 | `MEMORY.md` 每个主题一行要点（结论 + 适用条件）+ `topics/` 子文件 | 要点与子文件冲突时以子文件为准 |
| 足迹，可能还要包括一些索引 | 足迹 `daily/<日期>/`；时间索引是每日记忆的“已吸收足迹”，主题索引是主记忆，来源索引是 `state/sources.md` | — |
| 每日记忆：基于时间的记忆 | `daily/<日期>.md`，按工作日期，合并当天所有客户端 | 由整理生成 |
| 项目记忆：基于项目或路径，持续跟踪刷新；分总结的和详细的，详细的持续叠加 | `projects/<项目名>/`：意识是重写的总结；每日记忆与足迹是持续追加的详细；项目名等于平台项目根目录名 | — |
| 调取：AI 自己搜，告诉它怎么读取 | 读取协议 + 调取技能：常驻层 → 最近日记 → 主题 → 足迹 → 原件，用宿主的搜索工具 | 不需要检索服务 |
| 纯粹靠 skill 实现，不会很重 | 五个技能 + Markdown/TOML 文件；确定性靠清单文件和强制核对 | 无锁、无事务、无后台 |

## 用户级集中存储

默认数据根是 `~/.agents/memory/`，与当前工作区无关。同一台机器上的客户端共用；多台机器使用同一逻辑记忆库，由用户选择的同步方式保持一致。项目内容放在库内 `projects/<项目名>/`，不在工作区另建数据根或软链接。集中存储不代表项目结论跨项目适用，也不代表每次扫描全部项目。

Office Memory 后续迁入集中库并停用；迁移步骤见 [研究 demo 与已有资料](existing-data.md)。

## 完成程度

1.2.0 定义了结构、五技能方法、读取协议、Hook 模板、定时提示词和首次回填提示词。实际触发、长期运行效果，以及多客户端、多设备行为，需要宿主支持并完成相应验收，不能用文档声称已经具备。
