# XMemory

**跨客户端的记忆中心：五个技能，把各客户端的记忆和对话加工成一个按项目、按时间组织的集中记忆库。**

当前版本 **1.2.0**，文件格式名 `xmemory/v1`。插件只有技能和文档，没有运行期脚本、数据库、MCP、Hook 程序、后台服务或额外模型 API；执行靠宿主已有的读、搜、写和 shell 工具。

## 它做什么

```text
各客户端原生记忆、会话、工作区（只读）
  → 采集：记录（对话中实时）/ 采集（定时或手动）
  → 足迹：daily/<日期>/，一个会话一份，带可回查地址
  → 整理：一处单写，加工成意识、主记忆、主题、每日记忆、画像
  → 调取：先读常驻层，再按需展开，最后回原件
```

这是各家产品记忆机制的共同流水线：Codex 的逐会话提取与合并、QoderWork 的意识与反思、ZCode 和 Claude Code 的索引加主题、OpenClaw 的日记与 Dreaming。区别在于，它们只记各自客户端的东西；XMemory 用技能把整条流水线跑在所有客户端之上。

## 五个技能

| 技能 | 什么时候用 | 结果 |
|---|---|---|
| `xmemory-setup` 设置 | 初始化、发现并登记项目、登记来源、接入协议、Hook 和定时 | 配置与入口 |
| `xmemory-record` 记录 | 对话中被纠正、说明偏好、做出决定、要求记住或交接 | 新足迹（可加主题草稿） |
| `xmemory-collect` 采集 | 从各客户端记忆、指定会话、工作区变化中抽取；首次回填 | 新足迹、采集清单 |
| `xmemory-curate` 整理 | 加工未整理的足迹；合并、晋升、复查、更正、忘记 | 意识、主记忆、主题、每日记忆、画像 |
| `xmemory-recall` 调取 | 继续旧任务、查决定、找做法和坑、回看一段时间 | 只读回答 |

无需记命令名，直接说需求即可；重要任务可以在客户端技能选择器中显式选择。自然语言能否自动触发，取决于宿主和模型，不作保证。

## 结构

```text
~/.agents/memory/
├── config.toml           配置：项目、来源、时区、记录策略
├── USER.md               用户画像
├── AWARENESS.md          意识：现在该知道什么、该做什么、什么没定
├── MEMORY.md             主记忆：每条长期结论一行要点 + 项目入口
├── topics/<主题>.md      主题记忆：主记忆的子文件
├── daily/YYYY-MM-DD.md   每日记忆：当天概要
├── daily/YYYY-MM-DD/     当天的足迹
├── projects/<项目名>/    项目记忆，结构同上；项目名等于平台项目根目录名
└── state/                工作状态：来源进度、采集清单、整理记录、意识副本、撤回标识
```

这是用户主目录中的集中库，不是当前项目的 `.agents/memory/`。集中存储不代表项目规则自动适用于其他项目，也不需要给工作区建软链接。同一台机器上的客户端共用这个库；多台机器由用户选择的同步方式保持一致。

## 最短试用

先按 [安装说明](docs/install.md) 安装，再在隔离测试目录试用：

1. “设置 XMemory，在这个空目录初始化，时区按本机，登记 demo-api 项目；不接个人来源。”
2. “给 demo-api 记录交接：代码已改，测试结果由我报告，尚未部署，下一步验证部署。”
3. “整理 demo-api，保留所有尚未完成的旧事项。”
4. 新会话或另一个客户端中：“继续 demo-api，部署完成了吗？只读。”

预期能区分“报告测试通过”与本轮验证、“代码已改”与“已经部署”，并找到来源。完整案例见 [最小闭环](examples/walkthrough.md)。

长期使用时，按安装说明依次接入：
- [读取协议](integrations/entry.md)；
- [首次回填](integrations/backfill.md)；
- 可选的 [Hook](integrations/hooks.md)；

## 边界

- **读写分工**：调取只读。记录和采集只新建足迹；修改记忆正文的只有整理，同一时间只在一处整理。
- **定时整理的权限**：可以重写意识和每日记忆；合并、改写或撤回主题正文，只写成候选，由用户确认。
- **进度与核对**：采集先写逐项清单，核对后才推进进度；整理写后核对关键信息保全、已有条目损失、日期绝对化。
- **原生记忆只读**：各客户端的原生记忆、会话和 Office Memory 只读，不接管它们的格式，也不干预它们内置的后台记忆。
- **不做的事**：没有程序级锁或多文件事务；不监听目录、不创建定时任务、不同步设备。
- **范围与权限**：个人或项目范围不是企业权限；经验不会自动成为组织规则。
