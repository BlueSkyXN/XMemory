每个子目录是独立执行环境，内含 prompt.md、memory、输入和待测技能。分别交给无历史上下文的 GLM-5.3 / high；**不要给执行者本页或根目录的 evaluation-manifest.json**。使用虚构 HOME、独立最小 Codex 配置，关闭宿主记忆、插件、Apps、MCP、联网工具和其他代理。保留模型参数、输入快照、脱敏执行日志、原始产物和最终回答，凭据不进入夹具或提交内容。recall 用只读沙箱，其余只允许修改 memory 内的 Markdown。

## 核对方法

先检查命令、输入与技能哈希以及 memory 前后差异，再核对元数据、日期、归属、来源与正文。status、关键字或文件数量不能代替语义评分；preserve 的原样保留另比对输入块与输出。记录模型遗漏、过度表述和失败，不由监督者改好产物后宣称独立通过。

每个场景先运行一次。若因夹具或执行器错误重跑，保留原轮及具体原因；若修改产品规则，说明修改点并用新目录重跑相关场景。结果只证明该模型在这些合成任务上的表现，不证明真实宿主自然触发、定时执行、全历史覆盖或长期稳定性。实际结果见 [验证报告](../../docs/validation.md)，私有运行材料留在 local/。
