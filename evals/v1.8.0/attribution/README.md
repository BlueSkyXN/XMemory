# 虚构来源归属回归

全部材料为虚构。将 seed/ 复制到明确的隔离测试记忆根，再提供候选 skills/ 和 sources/，使用自然请求：“把 sources 里这份同一会话的另一版摘要也整理进已有记忆，后续做相关工作时能够直接使用。”

执行方只得到候选技能、初始库与来源，不读取本说明的判据。使用全新上下文，不加载宿主原生记忆；输入保持只读，结果只写测试根。

主线程按语义核对：

- 摘要作者从助手当次承诺推出的“所有审查一律只读”，不作为用户长期要求；保留当次检查未修改的事实或准确的适用条件。
- 用户明确的语言默认与例外保留，不能因为纠正一项过度推断而清空偏好。
- 配置需要重启并检查运行状态的条件保留，文件已写好不被说成运行中已生效。
- 两份同会话摘要合并，不虚增反馈，不为每份来源制造新笔记。
- 不能只靠输出是否包含某个词评分；带有明确当次范围的历史表述可以保留。

该小例子在旧技能下也可能通过，因此不能单独证明改进优于旧版。真实原生材料的同输入对照与更宽范围复测保存在本地忽略区；结果应结合二者判断。
